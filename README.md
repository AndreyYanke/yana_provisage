# yana_provisage

Одностраничный сайт визажиста Яны: портфолио, открытый прайс, обучение. Заявки уходят в Telegram, формы обратной связи нет.

**Боевой адрес:** https://yana-provisage-kzy8.vercel.app/
Ссылку клиенткам давать рано — на сайте подстановки вместо контактов и заглушки вместо фотографий, см. «Что осталось».

## Что где лежит

```
index.html    разметка и тексты
styles.css    все стили, включая токены дизайн-системы в :root
vercel.json   заголовки кэширования
brief.md      продукт, аудитория, прайс, состав блоков
research.md   рынок, эталоны, антипаттерны
```

Отдельной папки `design-system/` нет. Токены — цвет, шрифты, отступы, скорость анимаций — объявлены в `:root` в начале `styles.css`, компоненты используют только `var(--…)`. Заводить каталог превью не стали: на одностраничном сайте он дублировал бы сам сайт.

## Стек

Статика без сборщика. Ни зависимостей, ни `package.json`, ни шага сборки: `index.html` открывается двойным кликом, если `styles.css` лежит рядом. Публикация — коммитом в `main`, Vercel собирает сам.

Скрипта в браузере около 40 строк: появление секций при скролле, смена темы шапки на границе первого экрана и кнопка «Показать ещё» в портфолио. Всё остальное на CSS — вкладки портфолио работают на `:checked`, FAQ на `<details>`. Без JS страница читается полностью.

**Когда появится сборка.** Сейчас 63 карточки портфолио свёрстаны руками. При первой партии реальных фотографий контент переезжает в `content/*.json` и собирается шаблоном на деплое — вручную такую разметку не ведут. Решение и его обоснование записаны в [brief.md](brief.md) §12.

## Кэширование

`vercel.json` задаёт для `styles.css` заголовок `max-age=86400, stale-while-revalidate=604800`.

Зачем: по умолчанию Vercel отдаёт статику с `max-age=0, must-revalidate`, то есть при каждом повторном заходе браузер платит круговой рейс за проверку «не изменилось ли». Для HTML это правильно — он меняется вместе с контентом. Для стилей, которые меняются редко, это чистая потеря: замерено 150–200 мс на рейс.

Сутки свежести плюс неделя `stale-while-revalidate` означают, что вернувшийся посетитель не запрашивает стили вовсе, а после суток получает их из кэша мгновенно и обновление подтягивается фоном. Ручное версионирование не нужно, зависнуть на старых стилях навсегда невозможно.

Цена, которую это не отменяет: **на первом визите вынос стилей в отдельный файл стоит около 180 мс**, потому что браузер не может запросить `styles.css`, пока не получит HTML. Замеры до и после: полная загрузка 200 мс против 400 мс. В абсолютных числах это далеко от опасной зоны — обвал конверсии начинается после двух секунд ([research.md](research.md) §3.1) — но выигрышем по скорости разделение файлов не является и не задумывалось.

## Что осталось

Блокирует передачу ссылки клиенткам:

- фотографии по четырём категориям: образы, причёски, актрисы, съёмки
- адрес студии, станция метро, телефон
- ссылки на Telegram, канал, WhatsApp, VK, YouTube, Дзен, Instagram
- имя сайта и домен
- отзывы с Яндекс Карт
- три ответа FAQ помечены `[черновик]`

Все подстановки в коде помечены квадратными скобками. Список фактов, которые повторяются на странице в нескольких местах, — в комментарии-манифесте в начале `index.html`; его надо прочитать перед правкой любой цены.
