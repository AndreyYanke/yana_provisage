## Планируемая структура

Ещё не создано — это целевая раскладка, а не текущее состояние:

```
design-system/          источник правды по дизайну
├─ tokens/              tokens.json + tokens.css (цвет, шрифт, spacing, radius, motion)
├─ foundations/         превью: colors, type, spacing, motion
├─ components/          по папке на компонент: стили + preview.html
└─ patterns/            составные блоки (хедер, форма, hero)
```

Правила, на которых держится дизайн-система:

1. `tokens/tokens.css` — единственный источник цветов, шрифтов и отступов. В компонентах только `var(--…)`, хардкодных значений нет.
2. Каждый `preview.html` самодостаточен и открывается в браузере напрямую, поэтому работает как живая документация без сборки.
3. Первая строка каждого превью — маркер `<!-- @dsCard group="…" -->`. По нему Claude Design строит индекс карточек.

## Дизайн-система и Claude Design

Источник правды — папка `design-system/` в этом репозитории. Проект в [Claude Design](https://claude.ai/design) выступает зеркалом: компоненты выгружаются туда инкрементально, по одному, а не заливкой всего каталога целиком.
